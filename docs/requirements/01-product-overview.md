## 1. 背景

- 日本の若年女性の加工カメラ市場は「BeautyPlus 一強、SNOW が追う」構図です。レトロ系では Dazz・Huji が使われています（[02-competitors](../market-research/02-competitors.md)）。
- トレンドは「キャラ化」「平成レトロ」「自然盛り」「推し活」に分かれています。ユーザーは**複数のアプリやプリ機を使い分けている**状態です（[03-user-trends](../market-research/03-user-trends.md)）。
- AI 画像のバイラルが頻繁に起きている一方で、汎用 AI と競合する、推論コストがかかる、という課題があります（[04-ai-trends](../market-research/04-ai-trends.md)）。
- 写真アプリの★1レビューの約35%は課金の壁への不満で、公正な課金そのものが差別化要因になります（[05-monetization](../market-research/05-monetization.md)）。

## 2. 目的

**「盛れる・かわいい・懐かしい」を1つのアプリで完結させる。**
いまは美肌アプリ・レトロアプリ・プリ機・AI ツールを行き来している体験を、一つのアプリにまとめます。

## 3. コンセプト

> **「平成デジカメの質感で、ちゃんと盛れる。キャラにも、プリにも、AI でも。」**

1つのカメラに4つのモードを統合します。すべてのモードに共通する土台として、**レトロな質感（フィルム）と自然な美肌**を用意します。

| モード               | 概要                                                                                          | 市場調査での位置づけ                                      |
| -------------------- | --------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| **フィルム（主役）** | 平成デジカメ・CCD・ガラケー・使い捨てカメラ風の質感と自然な美肌を、撮影時にリアルタイムで適用 | 推奨案A。流行が長く続いていて、端末上で完結できる         |
| **キャラ**           | 顔に追従する動物系キャラエフェクト（耳・鼻・ほっぺ等）                                        | 案B。いま流行中（上位3つのエフェクトで82%）               |
| **プリ**             | プリ機のような連続撮影、台紙レイアウト、背景の合成、落書き                                    | 案C。空白領域で、平成プリのブームもある                   |
| **AI**               | 撮った写真を生成 AI で変身（フィギュア風・イラスト風など）                                    | 案D。バイラルを取り込む入口。クレジット制で原価を回収する |

### 差別化の原則

1. **撮って即完成**: 撮影時のリアルタイム加工を基本にし、後から編集もできる
2. **自然盛り**: 肌補正を最優先し、極端な変形は既定でオフ
3. **平成の文脈を深く再現**: 質感（CCD・ガラケー・使い捨てカメラ）と、デコ（日付・ネオンペン・平成ワードのスタンプ）
4. **公正な課金**: 基本機能・保存・透かしなしは無料。週額サブスク・強制ペイウォール・撮影画面の広告はなし
5. **端末上で処理**: AI モード以外は端末内で完結する（プライバシーに配慮し、原価が低く、オフラインでも動く）
6. **アプリを更新しないコンテンツ配信**: フィルム・キャラ・プリ台紙・スタンプをサーバーから追加する

## 5. スコープ

### 5.1 MVP に含めるもの（概要）

- 4モード（フィルム / キャラ / プリ / AI）。キャラ・プリ・AI はライト版
- 撮影・保存・後から編集・デコ（落書き・スタンプ・日付）
- アプリ内アルバム（簡易）、各 SNS への共有
- 無料＋年額・買い切りの課金、AI クレジット
- コンテンツ配信の基盤（フィルム・キャラ・台紙・スタンプの追加配信）
- iOS / Android の両 OS（Expo / React Native）
- 社内ツール: フィルムスタジオ（Web。アプリと同じシェーダーでフィルムを制作する。一般公開はしない）

詳細は [02-functional-requirements](02-functional-requirements.md) を参照してください。

### 5.2 MVP に含めないもの（Phase 2 以降）

- 動画へのキャラ・美肌の適用（短尺動画の撮影とフィルムの色は CAM-13 で対応）
- 友達とのリモート同時撮影（オンラインのプリ）
- 公開フィード・フォロー・DM などのソーシャル機能（未成年保護の観点から当面は作らない）
- 3D モデルのキャラアバター、全身の AR（頭の向きに追従する立体的な顔エフェクトは CHR-09 で対応）
- 英語など多言語への対応
- Web 版

## 6. 制約・前提

| 項目           | 内容                                                                                                                                                                                                                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 開発体制       | 個人開発（1名）。デザイン・素材制作も含む。開発者の TypeScript / React の経験は5年                                                                                                                                                                                                                       |
| 期間           | 6ヶ月で MVP をリリース（目標は2027年4月末）                                                                                                                                                                                                                                                              |
| 技術           | TypeScript のモノレポ。アプリは Expo（React Native）＋ VisionCamera v5 ＋ react-native-skia、顔検出は既存のネイティブプラグイン（ML Kit）、フィルムスタジオは React（Web）、サーバーは Firebase。シェーダー（SkSL）はアプリと Web で共有する。詳細は [07-system-architecture](07-system-architecture.md) |
| 予算           | 最小限（クラウドは従量課金・無料枠を活用する）                                                                                                                                                                                                                                                           |
| 対象地域・言語 | 日本・日本語                                                                                                                                                                                                                                                                                             |

## 7. 成功指標（KPI の仮置き）

| 指標                         | MVP リリース後3ヶ月の目標（仮）        | 根拠                         |
| ---------------------------- | -------------------------------------- | ---------------------------- |
| ストア評価                   | ★4.5 以上                              | 公正な課金を差別化の軸にする |
| D1 / D7 / D30 リテンション   | ベータ版で基準値を測ってから設定       | 競合データがない             |
| 課金率（MAU 比）             | 3% 以上                                | Meitu は 6.1%                |
| トライアルから課金への転換率 | 26% 以上                               | Photo & Video の中央値 26.2% |
| 撮影から共有への到達率       | ベータ版で基準値を測ってから設定       | 拡散の導線を検証する         |
| AI モードの粗利              | AI クレジットの売上 ≥ 推論コスト × 1.5 | 原価割れを防ぐ               |
| クラッシュフリー率           | 99.5% 以上                             | 品質の基本線                 |
