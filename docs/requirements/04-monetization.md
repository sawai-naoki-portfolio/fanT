# 04. 課金・価格設計

方針: **フリーミアム（年額＋買い切り）＋ AI クレジット**
根拠: [市場調査 05-monetization](../market-research/05-monetization.md)

## 1. 基本方針

1. 基本の撮影・保存・**透かしなし**は無料。無料でも「ちゃんと使える」こと
2. 週額サブスク・起動直後の強制ペイウォール・撮影画面の広告は**しない**
3. 価格・更新周期・解約方法を明確に表示する
4. AI は推論コストが重いため、**クレジット制で原価を回収**する。買い切りに AI の使い放題は含めない

## 2. プランと権利

| 機能・コンテンツ                 | 無料                                   | プレミアム（年額）                                 | プレミアム（買い切り）               |
| -------------------------------- | -------------------------------------- | -------------------------------------------------- | ------------------------------------ |
| 撮影・保存（透かしなし）・共有   | ✓                                      | ✓                                                  | ✓                                    |
| 美肌（基本）・肌のトーン         | ✓                                      | ✓                                                  | ✓                                    |
| 顔の微調整（目・輪郭）           | —                                      | ✓                                                  | ✓                                    |
| フィルム                         | 無料フィルム（4種程度）                | **すべてのフィルム**（毎月の新作を含む）           | すべてのフィルム（毎月の新作を含む） |
| 日付印字                         | ✓（標準の書式）                        | ✓＋書式・色のカスタマイズ                          | ✓＋カスタマイズ                      |
| キャラ                           | 無料キャラ（2種程度）                  | すべてのキャラ                                     | すべてのキャラ                       |
| プリの台紙・背景                 | 無料の台紙（2種程度）                  | すべての台紙・背景                                 | すべての台紙・背景                   |
| デコ（ペン・スタンプ・テキスト） | 基本のセット                           | すべてのスタンプ・フォント                         | すべてのスタンプ・フォント           |
| 後から編集                       | ✓                                      | ✓                                                  | ✓                                    |
| AI クレジット                    | 初回に3クレジットを無料で付与          | **毎月10クレジットを付与**（翌月への繰り越しなし） | なし（パックを購入）                 |
| 有料コンテンツのお試し           | プレビューで試せる。保存時に課金を案内 | —                                                  | —                                    |

> 買い切りは「AI 以外のすべて」を永続的に使えるプランです。ただし、将来の大型コラボなどの個別販売パック（PAY-08）は対象外にする可能性があります。購入画面に明記します。

## 3. 価格（仮）

| 商品               | 種別             | 価格（税込・仮） | 備考                                                  |
| ------------------ | ---------------- | ---------------- | ----------------------------------------------------- |
| プレミアム年額     | 自動更新サブスク | **2,800円/年**   | SNOW VIP の年額3,900円より安く設定。無料トライアル7日 |
| プレミアム買い切り | 非消耗型         | **6,800円**      | 年額の約2.4倍。Dazz の買い切りは年額の約2.5倍         |
| AI クレジット 10   | 消耗型           | 300円            | 1クレジットあたり30円                                 |
| AI クレジット 30   | 消耗型           | 800円            | 1クレジットあたり約27円                               |
| AI クレジット 100  | 消耗型           | 2,400円          | 1クレジットあたり24円                                 |

- 月額プランは MVP では**用意しない**（年額のほうが解約が少なく、ストア手数料も同じため）。ベータ版の反応を見て再検討します。
- 価格は RevenueCat の Experiments 等で A/B テストし、調整します。
- ストアの価格帯（ティア）に合わせて端数を調整します。

## 4. AI クレジットの採算（概算）

| 項目                                                 | 値（仮定）                                                                                                                                                           |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 生成1回あたりの原価（API ＋サーバー）                | 約5〜15円（採用するモデル・解像度で変わる。PoC で実測する）                                                                                                          |
| 1クレジットあたりの売上（ストア手数料15%を引いた後） | 約20〜25円                                                                                                                                                           |
| 粗利率の目標                                         | 50% 以上（KPI: AI の売上 ≥ 推論コスト × 1.5）                                                                                                                        |
| 年額会員への付与                                     | 10クレジット × 原価15円 = 月150円が上限。年額2,800円（手数料を引いて約2,380円）に対して約75%。**最悪のケースでは採算が厳しい**ため、付与数は原価の実測値を見て決める |
| 無料付与                                             | 3クレジット × 原価15円 = 1ユーザーあたり最大45円。獲得コストとして許容する                                                                                           |

→ 年額会員への付与数（10）は**未決事項**です（[06-open-issues](06-open-issues.md)）。

## 5. ペイウォールの表示ルール

| タイミング                                             | 表示内容                                                                           |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| 有料フィルム・キャラ・台紙を選んで保存しようとしたとき | 「このフィルムはプレミアムです」→ プラン比較                                       |
| AI クレジットが足りないとき                            | クレジットのパックと年額プラン（毎月付与）の比較                                   |
| 設定画面の「プレミアム」                               | プラン比較                                                                         |
| **しないこと**                                         | 起動直後・撮影直後の割り込み表示、閉じるボタンを隠す・遅らせる、誤タップを誘う配置 |

ペイウォールの必須表示項目（ストアの規約に従う）:

- 価格・更新周期
- トライアルの期間と、終了後に課金されること
- 解約方法
- 利用規約・プライバシーポリシーへのリンク
- 購入の復元

## 6. 決済手段

| 項目                   | MVP の方針                                                              |
| ---------------------- | ----------------------------------------------------------------------- |
| iOS                    | App Store のアプリ内課金。Small Business Program（手数料15%）に申請する |
| Android                | Google Play Billing（手数料15%）                                        |
| 外部決済（スマホ新法） | MVP では使わない。売上が大きくなったら、手数料の実額を比較して検討する  |
| 権利の管理             | RevenueCat（両 OS の購入状態を統合し、サーバーで検証する）              |

## 7. 未成年への配慮

- ペイウォールに価格と更新周期を大きく表示する
- iOS の「承認と購入のリクエスト」（ファミリー共有）と、Google Play の保護者による管理を妨げない
- 返金はストアの手続きに従い、その方法をサポートページに案内する
