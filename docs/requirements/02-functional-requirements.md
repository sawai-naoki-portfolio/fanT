# 02. 機能要件

## 優先度の定義

| 優先度                | 意味                                                    |
| --------------------- | ------------------------------------------------------- |
| **M（MVP必須）**      | これがないとリリースしない                              |
| **T（MVP目標）**      | MVP に入れたいが、スケジュールが遅れたら Phase 2 に回す |
| **L（Phase 2 以降）** | MVP には入れない                                        |

---

## 1. カメラ共通（CAM）

| ID     | 機能                 | 詳細                                                                                                          | 優先度 |
| ------ | -------------------- | ------------------------------------------------------------------------------------------------------------- | ------ |

| CAM-03 | 撮影                 | シャッターボタン（画面タップ・音量ボタンでも撮影できる）。撮影時の加工をそのまま反映した画像を生成する        | M      |

| CAM-06 | フラッシュ           | オフ / オン / 自動。フロントカメラは画面発光で代用する                                                        | M      |
| CAM-07 | タイマー             | 3秒 / 10秒                                                                                                    | M      |
| CAM-08 | ピント・露出         | タップでピント・露出を合わせる。露出をスライダーで補正する                                                    | M      |
| CAM-09 | ズーム               | ピンチでズーム。リアカメラのレンズ切り替え（対応端末のみ）                                                    | T      |

| CAM-11 | シャッター音・演出   | フィルムを巻き上げる演出（音・振動）。オン/オフ切り替え（無音撮影は OS の規約に従う）                         | T      |

| CAM-13 | 動画撮影             | 短尺の動画（最大15秒）を撮り、フィルムの色（LUT）と強さをかけて保存・共有する。キャラ・美肌の動画への適用は L | T      |

## 2. フィルムモード（FLM）: 主役

| ID     | 機能                     | 詳細                                                                                                                                                      | 優先度 |
| ------ | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| FLM-01 | フィルム選択             | フィルム（＝質感プリセット）を一覧から選ぶ。サムネイルにはリアルタイムのプレビューを出す（端末の性能が足りなければ静止画サンプルで代用）                  | M      |
| FLM-02 | 初期フィルム             | 無料4種＋有料4種以上。候補: 平成デジカメ（CCD）、ガラケー、使い捨てカメラ、インスタント（ポラロイド風）、プリ風、モノクロ、VHS 風（静止画）、夜フラッシュ | M      |
| FLM-03 | 質感エフェクト           | フィルムごとに組み合わせる: 色（3D LUT）、粒子、光漏れ（撮影ごとにランダム）、ブルーム（CCD のにじみ）、ビネット、色収差、低画素化、JPEG ノイズ           | M      |
| FLM-04 | 日付印字                 | オレンジの7セグメント風の日付を入れる。オン/オフ、日付は撮影日または任意の日付、書式（'26 10 24 など）                                                    | M      |
| FLM-05 | 強さの調整               | フィルムの効き具合を 0〜100% のスライダーで調整する                                                                                                       | M      |
| FLM-06 | ランダム性               | 光漏れや粒子のパターンを撮影ごとに変え、「一枚ごとに違う」偶然性を出す                                                                                    | M      |
| FLM-07 | フレーム                 | ポラロイド風の白枠、デジカメの液晶 UI 風（電池・枚数アイコン）など                                                                                        | T      |
| FLM-08 | お気に入り               | よく使うフィルムをお気に入りにして、先頭に表示する                                                                                                        | T      |
| FLM-09 | 「フィルム残り枚数」演出 | 使い捨てカメラ風に「残り27枚」と表示する遊び要素（任意でオン）                                                                                            | L      |

## 15. ジェスチャー操作（GST）

手を使わずに設定を切り替えるための操作です。**手動のボタン操作は常に使えます**。顔の検出結果は端末のメモリ上だけで扱います（[03](03-non-functional-requirements.md) §6）。

| ID     | 機能                | 詳細                                                                                                                                                                                                                                 | 優先度 |
| ------ | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------ |
| GST-01 | ウィンクで切り替え  | 本人から見て右目のウィンクで次のフィルム、左目のウィンクで美肌の強さを切り替える                                                                                                                                                     | T      |
| GST-02 | 誤動作の防止        | 片目を約0.7秒閉じ、もう片方が開いているときだけ反応する。両目が閉じたとき（まばたき）は無視する。反応した後は、目を開けるまで、かつ約1秒は反応しない。撮影中は反応しない。複数人が写っているときは、一番大きく写っている顔だけを見る | T      |
| GST-03 | オン/オフと割り当て | 設定画面で、オン/オフと、どちらの目に何を割り当てるかを変えられる（SET-01 の設定画面と同時に作る）                                                                                                                                   | T      |
| GST-04 | フィードバック      | 切り替えたら「美肌：強」のような表示と、軽い振動で知らせる                                                                                                                                                                           | T      |
| GST-05 | ほかのジェスチャー  | 口を開ける・首をかしげるなどで操作する                                                                                                                                                                                               | L      |

## 16. 社内ツール: フィルムスタジオ（STU）

| ID     | 機能                         | 詳細                                                                                             | 優先度 |
| ------ | ---------------------------- | ------------------------------------------------------------------------------------------------ | ------ |
| STU-01 | シェーダーのプレビュー       | サンプル画像（人物・風景・夜景など）に、アプリと同じパイプラインをかけて表示する。加工前後の比較 | M      |
| STU-02 | パラメーターの調整           | フィルム定義の全パラメーターをスライダーなどで調整し、すぐに反映する                             | M      |
