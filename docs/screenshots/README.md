## まだ撮れていない画面

撮影の自動操作の手順を直して撮り直し中です。撮れたら追加します。

- 設定・プレミアム（課金画面）・ライセンス: 直前に開いたキャラのシートが画面上部のボタンを覆い、設定を開くタップが届かなかった
- 写真の編集（全タブ）・写真画面・動かす・デコ: 写真ピッカーで写真をタップする位置がずれていた（見本の写真は一覧の先頭にある）
- コラージュ・HDR合成・パノラマ・AI: 撮影の手順にまだない
