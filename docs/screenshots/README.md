## まだ撮れていない画面

撮影の自動操作の手順を直して撮り直し中です。撮れたら追加します。

- 写真の編集（全タブ）・写真画面・動かす・デコ: 画面までは進めたが、写真が表示されず空白だった。写真はオフスクリーンの GPU サーフェスで描いており、その画像を画面上のキャンバス（別のスレッドと GPU コンテキスト）が描けなかったため（実機でも起こりうる不具合。CPU 側の複製を表示するように直した）
- 編集のタブ: 画面の中央をスワイプしていたためタブの列が横に動かず、「メイク」より右のタブを開けなかった（タブの列そのものをスワイプするように直した）
- コラージュ・HDR合成・パノラマ・AI: 撮影の手順にまだない
