### 2.3 レビュー評価（日本、集計サイト Unstar）[S-35][S-36]

- 苦情率が低い上位アプリ: Canon PRINT、Picsart（★4.5、苦情率0.1%未満）、InShot、Wink など
- ★1–2のレビュー総数が多いアプリ: Meitu の AI 編集、Pictlink、AI Mirror、Instagram、PhotoDirector
- → AI 加工アプリは、品質のブレや課金をめぐって不満が出やすい傾向があります。

### 2.4 リアルの競合: プリ機（フリュー等）

- 「盛れる」体験の基準を作っている存在です。Z世代女性の調査では、プリ撮影時の「ノーマスク」率が自撮り時より高く、その理由に「盛れる」が挙がっています [S-37]。
- 30周年企画として、平成の機種（姫組、THE CANDY STUDIO）を現行機で復刻しています [S-38][S-39]。
- 2025年の落書きランキングは、1位が平成風、3位がギャル風、5位がネオンペンでした [S-40]。

## 4. ポジショニングマップ（定性）

```
              リアル寄り（自然盛り）
                     │
      Lightroom/VSCO │  純正カメラ
                     │  BeautyPlus（美肌）
 撮影後に加工 ───────┼─────── 撮影時に加工（リアルタイム）
      Picsart/Canva  │  Dazz/Huji（レトロ）
      Remini/AI生成  │  SNOW/BeautyPlus（キャラ・AR）
                     │
              非リアル（キャラ化・AI変身）
```

**空白になりやすい領域**

- 「撮影時のリアルタイム」×「自然盛り」×「レトロ質感」を一つにまとめた体験
  - Dazz・Huji は美肌補正が弱いです。
  - BeautyPlus は総合アプリなので、レトロ体験は数ある機能の一つにとどまっています。
- 撮って終わりではなく、友達と一緒に盛る体験（プリ機のデジタル版）
