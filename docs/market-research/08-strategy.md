## 3. 推奨方針

### 3.1 ターゲット

- **第一ターゲット**: 国内の15〜24歳女性、iPhone ユーザー
- 典型例: プリ機・BeautyPlus・Dazz を併用していて、Instagram のストーリーズと鍵垢で共有する層

### 3.2 価値提案

> **「撮った瞬間、平成デジカメの思い出写真。肌は自然に、ちゃんと盛れる。」**

- アプリを2つ（美肌アプリとレトロアプリ）行き来しなくても、1枚で完成する
- 「別人」ではなく「いちばん盛れた自分」を、懐かしい質感で残せる

### 3.3 差別化の原則

1. **撮って即完成**: 撮影時のリアルタイム加工を基本にし、後から編集もできる
2. **自然盛り**: 肌補正を最優先し、極端な変形は既定でオフ
3. **平成の文脈を深く再現**: 質感（CCD・ガラケー・使い捨てカメラ）とデコ（日付・ネオンペン・平成ワードのスタンプ）の両方
4. **公正な課金**: 基本機能・保存・透かしなしは無料。週額サブスク・強制ペイウォール・撮影画面の広告はなし
5. **端末上で処理**: プライバシーに配慮し、原価が低く、オフラインでも動く
6. **運用力**: 新作フィルムやデコを毎月配信する（アプリを更新しない配信）

### 3.4 フェーズ案

> ※ 下の表は調査時点の案です。要件定義では、4モードを MVP に統合し、iOS / Android を同時に出すことに決まりました。→ [要件定義 01](../requirements/01-product-overview.md)

| フェーズ       | 内容                                                                                                                  |
| -------------- | --------------------------------------------------------------------------------------------------------------------- |
| Phase 1（MVP） | iOS。平成デジカメ風フィルム数種類、自然な美肌、日付印字、撮影と保存、後から編集、Instagram 共有、年額・買い切りの課金 |
| Phase 2        | デコ（ネオンペン・平成スタンプ・推し活フレーム）、フィルムの配信基盤、動画（短尺・VHS風）、ウィジェットやアルバム機能 |
| Phase 3        | キャラなりきり AR エフェクト、Android 版、軽い AI 機能（高画質化等）                                                  |
| Phase 4        | デジタルプリ（友達と共同で撮影）、コラボフィルム                                                                      |

### 3.5 KPI の目安（仮置き）

| 指標                         | 初期目標の目安 | 根拠                                         |
| ---------------------------- | -------------- | -------------------------------------------- |
| D1 / D7 / D30 リテンション   | 要設定         | 競合データがないため、ベータ版で基準値を測る |
| 課金率（MAU 比）             | 3〜6%          | Meitu は 6.1%                                |
| トライアルから課金への転換率 | 26% 以上       | Photo & Video の中央値は 26.2%               |
| ストア評価                   | ★4.5 以上      | 公正な課金を差別化の軸にする                 |
| 共有率（撮影から共有まで）   | 要設定         | Instagram ストーリーズの導線を検証する       |

## 4. 次に必要な検証（要件定義と並行して進める）

| #   | 検証                 | 方法                                                      | 目的                                                   |
| --- | -------------------- | --------------------------------------------------------- | ------------------------------------------------------ |
| 1   | 競合の実数           | Sensor Tower / AppMagic のトライアル                      | BeautyPlus・SNOW・Dazz・Huji の日本 DL 数と売上        |
| 2   | ユーザーインタビュー | ターゲット10〜20人＋Instagram アンケート                  | 課題・支払意欲・アプリの使い分けの確認。ペルソナの検証 |
| 3   | レビュー分析         | 競合上位5アプリの★1–2レビューを分類                       | 不満点を機能・方針に反映する                           |
| 4   | 技術検証（PoC）      | iOS で、リアルタイム LUT と粒子・美肌のプロトタイプを作る | 性能（fps、発熱、電池）と画質の確認                    |
| 5   | 価格テスト           | ペイウォールの A/B テスト（RevenueCat 等）                | 年額・買い切りの最適価格を探る                         |
