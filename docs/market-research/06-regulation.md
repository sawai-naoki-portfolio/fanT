# 06. 規制・制度環境（日本）

> 本章は事業検討のための整理で、法的助言ではありません。リリース前に専門家の確認を受けてください。

## 1. スマホソフトウェア競争促進法（スマホ新法）

| 項目         | 内容                                                                                                          | 出典             |
| ------------ | ------------------------------------------------------------------------------------------------------------- | ---------------- |
| 施行         | 2025年12月18日に全面施行                                                                                      | S-69, S-70, S-71 |
| 主な内容     | 外部決済の解禁、代替アプリストア、ストア外配布、ブラウザ・検索エンジンの選択画面                              | S-69             |
| 従来の手数料 | Apple: 小規模事業者 15%、大規模 30%                                                                           | S-72             |
| 新しい手数料 | 外部決済には新たな手数料（15〜20%程度との報道）がかかる。決済代行費と合わせると、従来より高くなるケースもある | S-72             |
| 違反時       | 売上の最大20%の課徴金                                                                                         | S-69             |

**示唆**

- 個人・小規模の事業者なら、当面は **App Store の Small Business Program（15%）** を使うのが最も簡単で有利です。
- 規模が大きくなったら、Web 決済への誘導を検討します（手数料の実額で比較）。

## 2. 個人情報・プライバシー

| 論点                 | 対応方針                                                                                                                                                                                 |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 顔画像               | 顔写真は個人情報にあたります。顔認証用の特徴量データは「個人識別符号」にあたる可能性があります（個人情報保護法）                                                                         |
| 端末上での処理を優先 | 撮影・加工は端末内で完結させ、画像をサーバーに送らない設計にします。生成 AI などで送信が必要な場合は、**明示的に同意を取り、保存期間・利用目的を明記**し、学習に使わないことを宣言します |
| iOS の要件           | カメラ・写真ライブラリへのアクセス目的の説明、App Privacy（栄養ラベル）、プライバシーマニフェストへの対応                                                                                |
| 分析ツール           | 年齢層を考えると、行動トラッキングは最小限にします。ATT（App Tracking Transparency）を求めない設計が望ましいです                                                                         |

## 3. 未成年ユーザー

主なターゲットが10代のため、次の配慮が必要です。

- **課金**: 価格を明確に表示し、誤って購入しにくい UI にします。iOS のファミリー共有・「承認と購入のリクエスト」に対応します。
- **年齢区分**: App Store の年齢区分に正しく設定します（競合は BeautyPlus 9+、SNOW 4+）。
- **ソーシャル機能**: 見知らぬ人とつながる機能（公開フィード、DM）は、**初期リリースでは入れない**ことを推奨します。モデレーションの負担と、未成年保護のリスクが大きいためです。
- **身体イメージへの配慮**: 過度な身体の改変（極端な痩身・輪郭変形）を既定でオフにし、「自然盛り」を基本にします。ルッキズムへの批判（[03](03-user-trends.md) の「加工の反動」）に配慮するためです。

## 4. 生成 AI・ディープフェイク

| 論点           | 対応方針                                                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 他人の顔の悪用 | 生成 AI の変換は、本人が写った写真だけを想定します。利用規約で他人の写真の無断加工を禁止します                                           |
| 性的な加工     | 生成 AI を入れる場合は、性的・暴力的な出力をフィルタリングします                                                                         |
| AI 生成の表示  | 生成 AI で作った画像には、メタデータ（C2PA 等）や表示で AI 生成と分かるようにすることを検討します                                        |
| 著作権         | 「ジブリ風」のような特定の作品・作家の画風を名指しするのは避けます。キャラクターエフェクトは**オリジナルか、正式なライセンス**に限ります |

## 5. 商標・知的財産

- 「写ルンです」「チェキ」などは他社の商標です。アプリ名・フィルター名・広告に使わないでください（例: 「使い捨てカメラ風」「インスタントフィルム風」と表現する）。
- 実在するカメラの外観をそのまま模したUIは避け、オリジナルのデザインにします。
- フォントやスタンプ素材は、商用ライセンスを確認してから使います。
