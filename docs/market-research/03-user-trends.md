## 2. 加工トレンド

### 2.1 キャラクター化

- BeautyPlus 利用者が使うエフェクトは、上位3つ（ピンクのくま・黒猫・うさぎ）で全体の **82.3%** を占めます。美肌補正やフィルター系は少数派でした（女子高生ラボ 2026年, n=51）[S-22]。
- 発表元の分析: 自撮りが「美肌・小顔補正」から「キャラになりきる」へ変わってきています。
- 示唆
  - **流行エフェクトをすばやく投入できる運用力**が必要です。
  - 流行の寿命は短く（数週間〜数ヶ月）、コンテンツを入れ替え続ける体制が前提になります。

### 2.2 平成レトロ

- **プリの落書き**: 2025年のランキングは、1位が平成風、3位がギャル風、5位がネオンペンでした。「ズッ友」「ニコイチ」などの平成ワードをネオンペンで書き、スタンプで派手にデコるのが人気でした。2026年のキーワードは「平成レトロ」です（フリュー）[S-40]。
- **プリ機の復刻**: 30周年企画で平成の機種を復刻し、平成プリのガシャポンも出ています [S-38][S-39]。
- **Z世代のトレンド調査**: 2026年上半期も平成レトロブームが加速しています（BELLOWL, n=116）[S-46]。
- **アプリ側の定番表現**: CCD風・デジカメ風・日付印字・光漏れ・粒子・色褪せ・VHS風・ガラケー画質・ポラロイド風 [S-47][S-48][S-49]
- **実機**: 写ルンです、チェキ Evo などの「平成カメラ」も人気です [S-50]。
- **海外**: Y2K / ヴィンテージの人気が続いています（ism、Dazz）。「AI 時代に人が撮ったことを感じさせる」質感への需要がある、という分析もあります [S-31]。

### 2.3 自然盛り

- Truesight Japan（Evoto）2026年4月, 18〜35歳女性, n=308 [S-51][S-52]
  - 写真の自分に自信がない人の **約8割** が、容姿に満足していない
  - 加工したい部位の **1位は「肌」**
  - 理想は「**自然に盛れる加工**」
  - 撮影目的は、SNS投稿より **「自分の思い出を残すため」** が多い
- 「別人にならない程度に盛る」が主流です [S-53]。
- 加工しすぎて、思い出の写真で自分や友達の元の顔がわからなくなった、という後悔の声もあります [S-54]。

### 2.4 無加工・リアル志向（BeReal 系）

- 約1割が「加工写真のトレンドに飽きた。自然な様子を共有したい」と回答しています（Appliv 2023年）[S-55]。
- BeReal の利用は、高校生で約3割です [S-44]。
- → 「盛らない」層も一定数います。**加工の強さを調整できること**（オフも含む）が重要です。

### 2.5 推し活

- BeautyPlus は日本のストア名に「**推し活**」を入れています [S-24]。
- プリのポーズランキングに「推しのグッズをもって」が入りました [S-40]。
- → 推しの色・推しのグッズと一緒に撮る用途（推し色フレーム、うちわ・アクスタと撮るモードなど）は、差別化の候補です。
