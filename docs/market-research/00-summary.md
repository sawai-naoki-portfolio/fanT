# 00. エグゼクティブサマリー

調査日: 2026-10-24
対象: スマートフォン向け写真加工・カメラアプリ（日本市場が中心。グローバル動向も含む）

## 結論（7つのポイント）

1. **市場は成熟しつつも成長中。** 写真編集アプリ市場の CAGR は推計で約5〜10%です。ただし収益は CapCut・Meitu・Picsart などの上位プレイヤーに集中しています。→ [01](01-market-size.md)
2. **日本の若年女性市場は「BeautyPlus 一強、SNOW が追う」構図。** 女子高生の利用率は BeautyPlus 56.6%、SNOW 21.1%（n=76の小規模調査）。レトロ系は Dazz と Huji が定番です。→ [02](02-competitors.md)
3. **加工のトレンドは多極化。** → [03](03-user-trends.md)
   - キャラ化: 動物エフェクトの上位3つで82%
   - 平成レトロ: CCD風・日付印字・ガラケー画質・プリの落書き
   - 自然盛り: 加工したい部位の1位は「肌」。別人にはしない
   - 推し活: BeautyPlus もストア名に「推し活」を入れている
4. **AI が主戦場。** Photo & Video カテゴリのサブスクアプリの61.4%が AI を搭載しています。ChatGPT や Gemini などの汎用 AI も、画像変換のバイラルを数週間単位で起こしています。→ [04](04-ai-trends.md)
5. **新規参入でも収益化しやすいが、課金への転換は難しい。** 新規アプリの月1,000ドル到達率は21.4%でカテゴリ中トップです。一方で、トライアルから課金への転換率は26.2%と低めです。★1レビューの約35%は課金の壁への不満です。→ [05](05-monetization.md)
6. **制度は追い風だが、効果は限定的。** 2025年12月にスマホ新法が施行され、外部決済が可能になりました。ただし新手数料があります。顔画像の扱いと未成年保護への配慮は必須です。→ [06](06-regulation.md)
7. **技術面は端末上の処理で十分戦える。** 10代女性の iPhone 比率は約85%です。リアルタイムのフィルター・美肌処理は、ネイティブの GPU パイプラインか商用 AR SDK で実現できます。→ [07](07-technology.md)

## 推奨する方向性（初期仮説）

**15〜24歳の女性に向けた「平成デジカメ × 自然盛り」のリアルタイム加工カメラ**。iOS を先に出します。

> ※ 要件定義では、4つのコンセプトをすべてモードとして統合し、iOS / Android を同時に出す（Expo / React Native）ことに決まりました。→ [要件定義](../requirements/README.md)

| 観点         | 理由                                                               |
| ------------ | ------------------------------------------------------------------ |
| 流行の持続性 | 平成レトロは令和に入ってから長く続いていて、2026年も加速している   |
| 原価         | 端末上で処理できるので、サーバーの推論コストがかからない           |
| 差別化       | グローバル大手が苦手な「日本ローカルの文脈」で戦える               |
| 拡張性       | キャラなりきりエフェクトや「デジタルプリ」を後から機能として足せる |

詳細は [08-strategy.md](08-strategy.md) を参照してください。

## 次に必要な検証

1. Sensor Tower / AppMagic のトライアルで、競合の日本での DL 数と売上を実測する
2. ターゲット層 10〜20人へのインタビューと、Instagram のアンケート
3. 競合上位5アプリの★1–2レビューを定量的に分析する
4. リアルタイムフィルターの技術検証（PoC）
5. ペイウォールの価格テスト
