**読み方**

- Photo & Video は「**少額の収益化はしやすいが、課金に転換させにくい**」カテゴリです。ライトユーザーが多いためです。
- 低価格はリテンションが高く、高価格は単価が高い、というトレードオフがあります。10代向けなら**低価格・高リテンション**を狙うのが合理的です。
- トライアルは長いほど転換率が高くなります。ただし、短期間だけ使うユーザーの多い写真アプリにそのまま当てはまるかは要検証です。

## 2. 課金モデルの比較

| モデル                     | 例                                          | 長所                                   | 短所                                                        |
| -------------------------- | ------------------------------------------- | -------------------------------------- | ----------------------------------------------------------- |
| サブスク（週）             | 多数の AI アプリ                            | 短期の売上が大きい                     | 「強気な週額」への反発が強く、★1レビューの原因になる [S-68] |
| サブスク（月・年）         | SNOW VIP（月900円 / 年3,900円）、BeautyPlus | 継続収益になる                         | 10代には心理的なハードルが高い                              |
| 年額＋買い切り             | Dazz Pro（年 US$19.99 / 買い切り US$49.99） | サブスク嫌いの層を取り込める           | 買い切り後の継続収益がない                                  |
| 少額の買い切り（機能単位） | Huji（120円）                               | 導入のハードルが最も低い               | 単価が低い                                                  |
| コイン・個別購入           | SNOW（フィルター・スタンプ）                | コンテンツを入れ替える運用と相性が良い | 設計が複雑になる                                            |
| AI クレジット（従量）      | 生成 AI 系                                  | 推論コストをそのまま転嫁できる         | 体験が分断されやすい                                        |
| 広告                       | 無料アプリ                                  | 課金しない層からも収益が出る           | 撮影体験を損なう。ブランドイメージが下がる                  |

## 3. ユーザーの不満（課金・広告）

- 写真編集カテゴリの★1レビューの **約35% がサブスク・課金の壁** に関するものです（Unstar の分析 2026年、単一ベンダーの分析）[S-68]。
- よくある不満
  - 「基本ツールの半分が Pro 限定」
  - 「無料に見える広告なのに、起動直後に課金を迫られる」
  - 「週額サブスクが高すぎる」
- → **公正な無料枠と明快な価格表示**そのものが差別化になります。

## 4. 推奨する課金設計（仮説）

| 区分               | 内容                                                                                                                                                       |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 無料               | 基本の撮影、主要フィルム（数種類）、美肌の基本、保存（**透かしなし**）、Instagram への共有                                                                 |
| 有料（年額プラン） | すべてのフィルム・カメラ、限定エフェクト、高度な美肌、日付・デコのカスタマイズ、月替わりの新作。**年額 2,000〜3,000円台** を想定（SNOW の3,900円より安く） |
| 有料（買い切り）   | すべての機能を永続的に使える（年額の約2〜2.5倍）。サブスクを嫌う層向け                                                                                     |
| 個別購入           | 季節限定・コラボのフィルムパック（数百円）                                                                                                                 |
| しないこと         | 週額サブスク、起動直後の強制ペイウォール、撮影画面への広告                                                                                                 |

価格は A/B テストで検証します（[08-strategy](08-strategy.md)）。
